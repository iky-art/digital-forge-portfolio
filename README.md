# DIGITAL FORGE — Portfolio Risky Pratama (Iky)

High-end 3D personal portfolio.

**Concept:** The Digital Forge — projects as planets in an interactive galaxy.

## Live (GitHub Pages)

Enable Pages in Settings → Pages → Deploy from branch `main` / root.

Then open: https://iky-art.github.io/digital-forge-portfolio/

## Stack

- HTML5 / CSS3 / Vanilla JS
- Three.js + GSAP
- Space Grotesk + Inter

## Run locally

```bash
python3 -m http.server 4173
```

## Features

- Interactive Three.js intro
- Galaxy projects (click planet = open project)
- Dark / Light theme
- Bahasa Indonesia UI
- Responsive & accessible
